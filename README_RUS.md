
# Портал School 21

Современный, адаптивный веб-интерфейс, разработанный для студентов School 21. Это приложение предоставляет комплексную панель управления (дашборд) для отслеживания прогресса, управления проектами, визуализации навыков и взаимодействия с сообществом пиров через интеграцию с Telegram.

## ✨ Возможности

### 👤 **Кабинет Студента**
- **Обзор Профиля**: Просмотр текущего уровня, XP, ранга в коалиции, кошелька (Coins) и очков проверок (PRP).
- **История Опыта**: Визуальный график траектории получения XP с течением времени.
- **Матрица Навыков**: Интерактивная визуализация приобретенных навыков и их уровней.
- **Активные Проекты**: Быстрый доступ к проектам, находящимся в статусах `IN_PROGRESS`, `IN_REVIEWS` или `WAITING_FOR_CORRECTION`.

### 🔍 **Поиск Пиров и Взаимодействие**
- **Поиск по Проектам**: Поиск других студентов, работающих над конкретными проектами (например, `CPP`, `ft_printf`) в разных кампусах.
- **Детали Участника**: Просмотр подробной статистики других студентов без выхода из контекста поиска.
- **Интеграция с Telegram**:
  - **Привязка Аккаунта**: Подключение Telegram-аккаунта через WebApp или Бота.
  - **Настройки Приватности**: Выбор между `Public` (юзернейм виден), `Notify Only` (разрешить анонимные уведомления от бота) или `Private`.
  - **Прямые Сообщения**: Быстрое открытие чата с пирами, привязавшими свои аккаунты.
  - **Уведомления от Бота**: Отправка уведомлений-напоминаний пирам о проверке, если они это разрешили.

### 🛠 **Инструменты Разработчика**
- **Debug View**: Встроенный API-эксплорер для тестирования эндпоинтов (`/v1/participants`, `/v1/projects`, `/v1/events` и др.) прямо из интерфейса.
- **Кэширование Данных**: Кэширование тяжелых запросов (Граф, Кампусы) в LocalStorage для повышения производительности.

### 🎨 **UI/UX**
- **Темная Тема**: Полная поддержка темной темы, синхронизирующейся с системными настройками или цветовой схемой Telegram WebApp.
- **Mobile First**: Оптимизировано для мобильных устройств и встраивания в Telegram WebApp.
- **Адаптивный Дизайн**: Плавно адаптируется под десктопные экраны.

## 🚀 Технологический Стек

- **Фреймворк**: [React](https://react.dev/) (TypeScript)
- **Сборщик**: [Vite](https://vitejs.dev/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **Управление Состоянием**: React Hooks & LocalStorage
- **Иконки**: Heroicons (SVG)

## 📦 Установка и Настройка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/Amazomic/school21.git
   cd school21
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Запустите локально**
   ```bash
   npm run dev
   ```

> **Примечание о доступе к API**: Это приложение полагается на специфические прокси-эндпоинты (`/api-proxy`, `/auth-proxy`) для связи с API School 21 и обработки OAuth токенов. Для успешного локального запуска убедитесь, что эти прокси корректно настроены в `vite.config.ts` или у вас есть бэкенд-сервис, обрабатывающий эти маршруты.

## 📱 Telegram WebApp

Это приложение спроектировано для работы в качестве Telegram Web App (TWA).
- Оно определяет окружение `window.Telegram.WebApp`.
- Автоматически адаптирует тему (Светлая/Темная) на основе настроек клиента Telegram.
- Использует `initData` для безопасной привязки аккаунта.
